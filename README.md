# ET617_endsem

Next.js app using the App Router, TypeScript, Tailwind CSS, and ESLint.

## Requirements

- Node.js 20.9 or later
- npm

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Start editing in `src/app`.

## Checks

```bash
npm run lint
npm run build
```

## Deploying

Import this GitHub repository into [Vercel](https://vercel.com/new), or install and sign in to the Vercel CLI, then run `vercel` from the project directory. Vercel detects the Next.js framework and configures the deployment.
