# ET617_endsem

Next.js app using the App Router, TypeScript, Tailwind CSS, and ESLint.

## Requirements

- Node.js 20.9 or later
- npm

## Local development

```bash
npm.cmd install
npm.cmd run dev
```

Open [http://localhost:3000](http://localhost:3000). Start editing in `src/app`.

In Windows PowerShell, use the `.cmd` launchers if script execution policy blocks the `npm` or `vercel` PowerShell wrappers.

## Checks

```bash
npm.cmd run lint
npm.cmd run build
```

## Deploying

Import this GitHub repository into [Vercel](https://vercel.com/new), or install and sign in to the Vercel CLI, then run `vercel.cmd` from the project directory in Windows PowerShell. Vercel detects the Next.js framework and configures the deployment.
